# CLAUDE.md - Developer Guide for Next.js AI App

## Commands
- Run dev server: `npm run dev`
- Build project: `npm run build`
- Run lint: `npm run lint`

## Code Guidelines
- Use Next.js App Router and TypeScript.
- Follow modular architecture (`src/components`, `src/services`, `src/types`).
- Use Tailwind CSS for styling.
- Ensure proper error handling and TypeScript interfaces for all API responses (OMDb / Firebase).
